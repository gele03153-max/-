# Magnesium electrolyte Perspective Version 5

英文主体 6,014 词；含两张表 6,601 词。140 篇唯一 DOI 文献、9 个共同 CE 案例、7 组机制证据问题和四幅更新主图。

- `Magnesium_Perspective_V5.docx`：英文稿，AM 风格双栏正文，含可编辑三线表。
- `Magnesium_Perspective_V5.pdf`：完整阅读稿。
- `Table_1_three_line_V5.docx`：独立一页三线表，统一五列，所有案例都有 Mg CE。
- `Manuscript_V5.md`：可在 GitHub 查看的正文、图、表和文献。
- `V5_中文修改说明.md`：五项要求的对应修改和证据范围。
- `DOI_140_readable.md`、`References_DOI_140.csv`：可读 DOI 清单、编号与引用定位。
- `References_140.ris`、`References_140.bib`、`References_metadata.json`：文献导入及身份核验记录。
- `Reference_paragraph_table_map.csv`、`Paragraphs_and_table_rows.json`：正文/表格与文献的对应关系。
- `Performance_data_source_audit.csv`：每个 CE 的出处、原始摘要/二手来源标记和测试条件边界。
- `Tables_V5.md`、`Table_1_editable.csv`、`Table_2_editable.csv`：独立表格内容。
- `Figure_1.png` 至 `Figure_4.png`、`Figure_scientific_audit.md`：四幅主图和科学逻辑核查。
- `Validation.json`、`SHA256SUMS.txt`：格式、引用、分页与完整性记录。

Table 1 的共同指标不代表共同测试条件；CE 不作为去溶剂化能垒或速率的直接测量。140 篇文献的 DOI 身份和题名核对沿用前版，原始全文及补充材料尚未全部独立核读，范围见审计表。
