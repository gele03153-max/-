# Magnesium electrolyte Perspective — Version 3

第三版保留原框架的六章顺序。正文主体 6,091 个英文词；含两张表为 6,717 词，不含标题、摘要、图注和参考文献。

主要文件：

- `Magnesium_Perspective_V3.docx`：可编辑英文稿，含两张原生表格和四幅主图。
- `Magnesium_Perspective_V3.pdf`：14 页阅读稿。
- `Manuscript_V3.md`：可在 GitHub 直接查看的正文、图、表及参考文献。
- `DOI_140_readable.md`：140 篇文献的 DOI 链接与引用位置。
- `References_DOI_140.csv`、`References_140.ris`、`References_140.bib`：文献清单及导入文件。
- `Table_1_editable.csv`、`Table_2_editable.csv`、`Tables_V3.md`：独立表格。
- `Performance_data_source_audit.csv`：16 组性能数据的出处与已核验范围。
- `Reference_paragraph_table_map.csv`：211 条段落/表格与文献对应关系。
- `Figure_1.png` 至 `Figure_4.png`、`Figure_scientific_audit.md`：主图与科学逻辑复核说明。
- `V3_中文修改与证据说明.md`：中文修改说明、字数口径和证据边界。
- `Validation.json`、`SHA256SUMS.txt`：文件、引用、分页及完整性检查记录。

完整 ZIP 解压后可离线打开 Word、PDF 和所有附件。DOI 登记记录及题名已核对；原始全文和补充信息尚未全部独立核读。表 1 的 P 标记指已读原论文摘要中的数值，S 标记指所提供 AM Perspective 中的数值，详细出处列于审计表。四图是概念示意栅格图。
